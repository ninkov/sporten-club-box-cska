# Спортен клуб бокс ЦСКА

Базов уебсайт за спортен клуб по бокс ЦСКА, изграден с React и Vite.

## Какво съдържа

- Начална секция с основно представяне на клуба
- Навигация с мобилно сандвич меню
- Секции „За нас“, „История на клуба“, „Треньори“, „Галерия“, „Проекти“ и „Контакти“
- Responsive дизайн за desktop и мобилни устройства
- Лого на клуба и favicon с емблемата на ЦСКА

## Инсталация

```bash
npm install
```

## Стартиране за разработка

```bash
npm run dev
```

След стартиране сайтът обикновено е достъпен на:

```text
http://localhost:5173/
```

## Проверки

```bash
npm run lint
npm run build
```

## Основни файлове

- `src/App.jsx` - подрежда основните секции
- `src/components/` - React компонентите на страницата
- `src/index.css` - всички стилове на сайта
- `src/assets/` - изображенията, използвани в сайта
- `public/favicon.jpg` - favicon иконата
